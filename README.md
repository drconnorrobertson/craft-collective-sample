# Craft Collective Salon Group

Static marketing site for Craft Collective Salon Group — 90 pages serving the
greater Pittsburgh area from studios in the North Hills (2014D Babcock Blvd)
and Canonsburg (115 W Pike St). Deployed on Vercel.

## Layout

```
index.html                     home
services/<service>/            9 service pages
locations/<area>/              20 location + service-area pages
team/<stylist>/                39 stylist pages
blog/<post>/                   10 posts + index
assets/site.css                theme + responsive layer (shared)
assets/site.js                 mobile nav + FAQ accordion (shared)
optimize.py                    the build pass, see below
sitemap.xml                    generated by optimize.py
```

Every page carries its own inline `<style>` for layout. `assets/site.css` is
loaded immediately after it on every page, so equal-specificity rules there win
on document order — that is where the theme, the responsive rules and the shared
components live. Page-level styles are not edited directly.

## The build pass

`optimize.py` normalises all 90 pages to one standard and regenerates the
sitemap. It is idempotent — everything it injects sits between `<!-- cc:NAME -->`
markers and is stripped before being rewritten, so running it twice produces a
byte-identical tree.

```bash
python3 optimize.py
```

It handles:

- **Schema** — one `Organization` node per page (not `LocalBusiness`: the group
  serves an area, it is not a single storefront), `FAQPage`, `BreadcrumbList`,
  and `BlogPosting` on posts. FAQ copy and FAQ markup are generated from the
  same source so they can never drift; the three pages that ship their own
  visible accordion have their schema scraped back off the page instead.
- **Meta** — title, description, canonical, Open Graph and Twitter rewritten as
  one consistent set, with titles fitted to the ~62 character SERP link.
- **Conversion** — sticky call/book bar, trust strip, cross-link row.
- **Accessibility** — skip link, `#main` target, and removal of inline colour
  overrides left over from the previous dark theme.

To add a service, area or post, add it to the relevant table near the top of the
script (`SERVICES`, `AREAS`, `BLOG_POSTS`) along with its FAQ entries, then
re-run.

## Local preview

```bash
python3 -m http.server 4321
```

Vercel serves clean URLs (`/book`, not `/book/index.html`); `python3 -m
http.server` redirects `/book` to `/book/`, which is close enough for review.
