# Craft Collective Salon Group

Static marketing site for Craft Collective Salon Group — 90 pages serving the
greater Pittsburgh area from studios in the North Hills (2014D Babcock Blvd)
and Canonsburg (115 W Pike St). Deployed on Vercel.

## Layout

```
index.html                     home
services/<service>/            9 service pages
locations/<area>/              20 location + service-area pages
team/<stylist>/                39 stylist pages
blog/<post>/                   10 posts + index
404.html                       hand-authored, excluded from the build
assets/site.css                theme + responsive layer (shared)
assets/site.js                 mobile nav, FAQ accordion, scroll reveal
optimize.py                    the build pass, see below
sitemap.xml                    generated by optimize.py
favicon.* / icon-* / og-card   generated brand assets
```

Every page carries its own inline `<style>` for layout. `assets/site.css` is
loaded immediately after it on every page, so equal-specificity rules there win
on document order — that is where the theme, the responsive rules and the shared
components live. Page-level styles are not edited directly.

## The build pass

`optimize.py` normalises all 90 pages to one standard and regenerates the
sitemap. It is idempotent — everything it injects sits between `<!-- cc:NAME -->`
markers and is stripped before being rewritten, so running it twice produces a
byte-identical tree.

```bash
python3 optimize.py
```

It handles:

- **Schema** — `Organization` and `WebSite` on every page (not `LocalBusiness`:
  the group serves an area, it is not a single storefront), plus `FAQPage`,
  `BreadcrumbList`, `Service` on service pages, `BlogPosting` on posts, and
  `ItemList` rosters for the team and the reviews. Everything user-visible is
  generated from, or scraped back off, the rendered page, so the markup can
  never claim content the page does not show.
- **Meta** — title, description, canonical, Open Graph and Twitter rewritten as
  one consistent set, titles fitted to the ~62-character SERP link, and social
  images re-cropped to a true 1200×630.
- **Images** — `srcset`/`sizes` per layout role, intrinsic `width`/`height` from
  a probed dimension table, `decoding=async`, exactly one eager LCP candidate
  per page with a matching `<link rel=preload>`, everything else lazy.
- **Conversion** — sticky call/book bar, trust strip, cross-link row, and a
  full-bleed photograph on every service, location and blog page.
- **Performance** — the Google Fonts stylesheet is taken off the critical path
  with a `<noscript>` fallback.
- **Accessibility** — skip link, `#main` target, `aria-current` on the nav, and
  removal of inline colour overrides left over from the previous dark theme.

To add a service, area or post, add it to the relevant table near the top of the
script (`SERVICES`, `AREAS`, `BLOG_POSTS`, `SERVICE_ART`) along with its FAQ
entries, then re-run.

### Regenerating the brand assets

`favicon.ico`, `apple-touch-icon.png`, `icon-*.png` and `og-card.jpg` were
generated with Pillow and are committed. `favicon.svg` is hand-drawn so the
mark needs no font to render.
